# Project Workspace

This folder is your **coding workspace** — it is mounted as `/project` inside the AI Dev Box virtual machine.

Place your code, files, and projects here. Changes made on your host machine are immediately available inside the VM, and vice versa.

## Getting Started

```bash
# Start the VM (from the repo root)
vagrant up

# SSH into the VM
vagrant ssh
```

## Notes

- The `Vagrantfile` and VM configuration files are **not** accessible from inside the VM — only the contents of this folder are shared.
- AI coding agents running inside the VM can only read and write files within this folder.
- `opencode.json` is auto-generated by the VM provisioner and is gitignored.
